# DCAM

## Description

Trang trung tâm vận hành dự án **DCAM** trong không gian tài liệu DVID.

Trang này dùng làm project root. Thành viên mới nên bắt đầu từ **DCAM Project Home** để đọc cấu trúc tài liệu, thứ tự đọc, tài liệu quan trọng, trạng thái tài liệu hiện tại và các bước tiếp theo của dự án.
