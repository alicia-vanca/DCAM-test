## Rules

- Maintain one execution tracker: `plans/mvp-delivery-plan.md`.
- Put procedures under `plans`; put results under `evidence`.
- Do not copy checklist status into summaries, indexes or evidence pages.
- Do not treat local developer notes as approved requirements.

Legacy Sprint 0 summary/index/checklist files remain as compatibility pointers only.
